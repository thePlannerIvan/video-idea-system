# 批评清单

候选自筛和成稿后各用一次，检查深度随阶段变化；用户只要审稿时直接进入。目标是指出有依据的错误、理解障碍或未兑现的表达，不把所有视频改成同一种样子。

## 候选阶段：只诊断当前能判断的内容

生成结束后，用下面六项中适用的部分检查：是否服务确认的核心；动作与意思的关系是否能讲清；关键事实和演绎身份是否正确；开始、变化、结束是否兑现该候选的承诺；最低资源是否可获得。完整结构与段落零件按各自用途判断，零件不必独立讲完整片。

关系断裂、偏题或需要伪造事实的点子剔除；局部可修就修；尚缺素材或实验结果未知时，说明成立条件与替代分支，再决定是有条件保留还是暂存。资源较高、审美陌生和无法保证受欢迎本身不是错误。诊断依据必须指向点子中的具体问题，不用想象的观众反应冒充验证。

此时不检查尚未写出的口播用词、句长或全片段落节奏。自筛记录留后台，展示页只给作者影响选择的风险与取舍。

## 成稿与录后阶段：六项检查


| 检查 | 对照什么、如何诊断 | 边界 |
|---|---|---|
| **作者意图** | 将当前稿/交接与用户题目、明确反馈、批准决定对照。是否改了立场、抹掉原有矛盾，或让例子接管了主题？指出具体偏移。 | 意图未定就标暂定，不代作者锁定“更尖锐”的结论。 |
| **事实与推断** | 找关键事实、因果、动机和实验结论的材料依据；区分亲历、转述、解释、假设、演绎与实测。检查结论是否超过证据。 | 引用作者不代表外部事实已核实；换因果措辞不消除偏差；不补第一人称经历来改语气。 |
| **理解与逻辑** | 沿第一次接触材料的顺序读：指代有无对象，转折/因果是否有前提，概念是否中途换义，是否自相矛盾。指出具体歧义或缺口。 | 隐喻、口语、不解释一切并非错误；朗读风险可以建议试念，不能凭模型偏好认定。 |
| **推进与兑现** | 开头/中途实际许诺的内容后来是否出现；关键转折能否由已有铺垫接住；重复是否没有新作用。定位承诺与兑现或缺失处。 | 无须每条有悬念、序数词、反转、CTA或结尾总结。悬而未决也可以是作者批准的表达。 |
| **机制落地** | 针对所选概念，核对所需声音/动作/对象/参与是否在稿、拍摄计划或真实素材中各有对应，降级是否改变了机制。 | 计划中出现不算已经拍到；清讲不强制画面；缺实拍不能用后期伪装成证据。 |
| **修订保真** | 把修改前后对读：是否丢了必要限定、个人语气、情绪、关键证据或作者有意的回声；是否新增未经支持的内容。 | 风格偏好不冒充语病。修订本身造成的问题同样撤回。 |

## 输出与修订

只输出实际发现的问题，按影响大小排列，不逐项填“通过”，也不为完成清单制造缺陷。每条写：

> **位置与原文/缺失处 → 问题及依据 → 对表达的影响 → 最小修法。**

一句话问题引用原句；结构问题可定位到段落或缺失的连接，不强行找一句“违规句”。证据不足与表达不清分开，审美或朗读偏好标为可选建议。没有足够依据就不判错，可以确认无需修改。

需要补事实时标待确认，不能代作者补写。局部问题给局部修订；用户要求完整修订稿时再交全文。改变意图或证据强度的大改回到作者讨论，小修在授权范围直接完成。

修订后复查受影响的上下文与关键主张即可，不无限循环，也不因用户没有回答一个非必要问题就扣住可交付内容。

## 不进入固定诊断的内容

平台权重、所谓黄金秒数、最佳句长、投入比例、爆款套路、固定开头和结尾模板不是普遍真理。只有用户明确目标或当前材料给出具体理由时，才在相应工作中讨论；不通过这些预设给创意判不合格。
